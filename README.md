# Juego de Divisiones

Juego para aprender a dividir paso a paso con el método de la galera.

## Instalar

| Dónde | Descarga |
| --- | --- |
| **PC (Windows)** | [Juego de Divisiones Setup 1.3.4.exe](https://github.com/nasa-cell/juego-de-divisiones-con-procedimiento/releases/download/v1.3.4/Juego.de.Divisiones.Setup.1.3.4.exe) |
| **Celular (Android)** | [Juego de Divisiones 1.3.4.apk](https://github.com/nasa-cell/juego-de-divisiones-con-procedimiento/releases/download/v1.3.4/Juego.de.Divisiones.1.3.4.apk) |

**En la PC**

1. Descarga el archivo `.exe` y ábrelo.
2. Si Windows muestra «Windows protegió su PC», pulsa «Más información» y luego «Ejecutar de todas formas».
3. Elige para quién se instala y en qué carpeta, y pulsa «Instalar».

**En el celular**

1. Descarga el archivo `.apk` desde el celular y ábrelo.
2. Si Android pide permiso para instalar aplicaciones de esta fuente, acéptalo.
3. Pulsa «Instalar».

Instalar una versión nueva encima de la anterior conserva los alumnos y su progreso.

## Qué hace

- Divisiones por el método de la galera, rellenando casillas paso a paso. Al 4.º error el juego enseña la división y luego da una parecida.
- Dos modos: **sin reloj** (niveles Fácil, Medio, Difícil y Avanzado, rondas de 13) y **con reloj** (escalera 3D de 12 escalones que el juego sube o baja solo, con el tiempo calculado según la velocidad de cada alumno).
- Aprende de cada alumno (pasos donde falla, tabla que más le cuesta, velocidad) y crea problemas nuevos a su medida.
- Pistas con los números de cada casilla y ayuda que se va retirando a medida que el alumno acierta solo.
- Alumnos con nombre y dibujo o foto propia, «Mi progreso» con gráficas y medallas, e informe PDF para los padres.
- Funciona sin internet y guarda los datos en el propio equipo.
